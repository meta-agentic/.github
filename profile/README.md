Meta-Agentic builds the operating system for autonomous AI agents, in the open: the framework agents run on, the disciplines they work by, and the products built that way. More at [meta-agentic.ai](https://meta-agentic.ai).

### The agent operating system

- [**meta-os**](https://github.com/meta-agentic/meta-os): the framework for Claude Code and Obsidian, with the skill backbone, the agent operating model and the raw → wiki → output memory conventions.
- [**meta-disciplines**](https://github.com/meta-agentic/meta-disciplines): the discipline skill packs (agents, agile, math, physics, software engineering), installable as Claude plugins from the `meta-agentic` marketplace.
- [**meta-cli**](https://github.com/meta-agentic/meta-cli): fans headless agent runs out to several engines and keeps their run artifacts.
- [**meta-os-dashboard**](https://github.com/meta-agentic/meta-os-dashboard): sprint lanes with flow forecasts, the knowledge graph and memory promotion, read straight from the vault.
- [**meta-ethics**](https://github.com/meta-agentic/meta-ethics): a constitution for mixed groups of humans and AI agents, written as rules a program can apply.

### Products

- [**meta-iam**](https://github.com/meta-agentic/meta-iam): a multi-tenant OpenID Connect and OAuth 2.0 authorization server on Quarkus, fail-closed by design.
- [**meta-tracker**](https://github.com/meta-agentic/meta-tracker): an agile tracker built in the open, with its own backlog versioned in the repository.
- [**meta-snmp**](https://github.com/meta-agentic/meta-snmp): an agent-ready SNMP toolkit.
- [**meta-retro**](https://github.com/meta-agentic/meta-retro): firmware and OS lifecycle for retro handhelds, with checksum-verified card dump and flash.
- [**meta-latex-template**](https://github.com/meta-agentic/meta-latex-template): one LaTeX identity for papers, slides and handbooks, with a reproducible build.

Security reports go through GitHub private vulnerability reporting on the affected repository; see the [security policy](https://github.com/meta-agentic/.github/blob/main/SECURITY.md).
